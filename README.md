# Sliding Puzzle Diario con Mascotas *(nombre tentativo)*

Juego web de sliding puzzle 4x4 con una imagen diaria distinta para todos los jugadores, leaderboard diario y un ángulo comunitario: en fases futuras, los propios jugadores podrán subir fotos de sus mascotas para que aparezcan como el puzzle del día.

**Estado actual:** Planificación — Fase 1 (MVP) en definición. Meta de lanzamiento: 5 semanas desde el inicio de desarrollo.

**Nota:** este repositorio, además de contener el proyecto real, documenta el proceso completo de planificación como práctica de portafolio profesional en Project Management, Business Analysis, Product Ownership y Scrum Mastery.
